# Xixi · 互动场景

一个完全静态的互动照片场景。GitHub 保存完整源码，Cloudflare Pages 提供不含 GitHub 用户名的公开网址。运行时不调用 GPT，也不需要 API Key。

## 已有功能

- 手机和电脑自适应
- 多张照片与 GIF 上传、拖动、缩放、删除、图层顺序、透明度
- 酒店落地窗、温馨卧室或自定义背景
- 点击问候、流水声、照片绑定互动
- 浏览器自带中文文字朗读，可调设备声线、语速和音调
- 多个自定义音频顺序播放与循环
- 可把任意上传音频设为“欢迎回来”的默认问候
- 简易本地抠图（纯色或干净背景效果最好）
- IndexedDB + localStorage 自动保存；每个人只看到自己设备上的内容
- 可选择是否保存本次设置；关闭保存时，下次从默认页面开始
- 可随时恢复默认图片、背景和交互设置
- PWA 离线缓存

## 最常改的内容

打开 `config.js` 即可集中修改：

- `siteName`：网站名称
- `greetingText`：默认气泡文字
- `defaultPerson`：默认人物图片路径
- `defaultBackground`：默认背景图片路径

换默认人物图时，也可以直接用新图片替换 `assets/default-person.jpg`，保持文件名不变。网页里的上传、拖动、缩放、图层、透明度和音频设置仍然全部由用户在页面上操作，不需要改代码。

## 发布（网址不含 GitHub 用户名）

1. 把本目录的全部文件放进 GitHub 仓库的 `main` 分支（不是只上传 HTML）。
2. 在 Cloudflare Pages 连接这个 GitHub 仓库。
3. 构建设置选择静态站点：无需构建命令，输出目录填 `/`。
4. 发布后使用 `xixi.pages.dev` 或 Cloudflare 分配的同类地址，不出现 GitHub 用户名。

以后在 GitHub 修改并提交文件，Cloudflare Pages 会自动重新发布。

## 隐私与声音说明

用户上传的照片和音频只保存在当前浏览器，不会写入 GitHub 仓库。文字朗读使用设备自带的系统声线，不克隆、不模仿或冒充任何真实人物。
